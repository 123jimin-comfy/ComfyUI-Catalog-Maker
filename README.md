# ComfyUI-Catalog-Maker

This is a tool for creating catalogs for T2I (text-to-image) models on ComfyUI.

A few examples of catalogs are:

- Checkpoint catalogs: A catalog of images, for same prompts, generated by different checkpoints.
- Prompt catalogs: A catalog of images with slightly different prompts.
- Grid plots: A grid of images with different parameters across each axis.

## Instruction

```bash
make-comfy-catalog -b backend.toml catalog.toml output
```

- `backend.toml`: Backend config file.
  - `comfy`: Specifies the ComfyUI server.
  - `parameters`: Specifies common checkpoint-specific parameters for all catalogs.
- `catalog.toml`: Catalog config file. Specifies the catalog to create.
  - `axes`: Specifies the axes of the catalog.
  - `parameters`: Specifies catalog-specific parameters.

## Example Config File

### Backend Config File (backend.toml)

```toml
[comfy]
host = "example.ai:8188"

[comfy.auth]
# If you're using HTTP Basic Auth
username = "alex"
password = "hunter2"

[[parameters]]
# Parameters without pattern will be applied to all checkpoints.
# Check src/config/parameter.d.ts for all available parameters.
width = 896
height = 1152

[[parameters]]
pattern = "sdxl*/**"
workflow = "sdxl"
styles = ["SDXL"]
```

### Catalog Config File (catalog.toml)

This is an example for creating a 2D grid of cfg/steps.

```toml
id = "cfg_steps"
name = "CFG x Steps"

[[parameters]]
checkpoint = "sdxl/foo.safetensors"
prompt = "1girl, solo, outdoors, casual, looking at viewer, full body"

[[axes]]
id = "cfg"
name = "CFG"
target = "cfg"

[axes.range]
type = "float"
min = 1.0
max = 20.0
num_steps = 19

[[axes]]
id = "steps"
name = "Steps"
target = "steps"

[axes.range]
type = "enum"
values = [1, 2, 4, 8, 16, 32, 64]
```
